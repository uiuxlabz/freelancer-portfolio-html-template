# Freelancer Portfolio HTML Template -- DEVFOLIO

A warm, approachable freelancer and developer portfolio template. Framework-free, responsive, and beautiful. Built with semantic HTML, modern CSS custom properties, and vanilla JavaScript -- zero dependencies.

---

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, about preview, projects grid, services, team, testimonials, blog, contact CTA |
| About | `about.html` | Story band, skills with animated bars, team section, experience timeline |
| Projects | `projects.html` | Full masonry portfolio grid with category filters and CTA band |
| Contact | `contact.html` | Contact form with validation feedback, info cards, and background band |

---

## Design Distinction -- 6-Axis Comparison

| Axis | DevFolio | Typical Sibling Templates |
|------|----------|---------------------------|
| **Color System** | Indigo + Amber + Cream -- warm, inviting palette with CSS custom properties | Generic blue/gray or neon-heavy schemes |
| **Typography** | Triple-font stack: Poppins (display), Nunito Sans (body), IBM Plex Mono (code) | Single font or system stack |
| **Warmth** | Cream backgrounds, amber accents, rounded badges, friendly microcopy | Cold whites and sharp edges |
| **Motion** | Scroll-reveal animations, floating skill badges, smooth carousel, skill bar fills | Static layouts or basic fade-ins |
| **Layout** | Masonry portfolio grid, timeline experience, story-band about section | Standard card grids and plain lists |
| **Developer Experience** | Zero dependencies, semantic HTML, accessible markup, section-scoped styles | Heavy framework reliance, bloated builds |

---

## Features

- **Framework-free** -- pure HTML, CSS, and vanilla JS. No build step, no npm install.
- **Responsive** -- mobile-first with breakpoints at 480px, 768px, and 1024px.
- **Accessible** -- ARIA labels, semantic landmarks, keyboard-navigable.
- **Animated** -- IntersectionObserver-driven scroll reveals, skill bar fills, testimonial carousel.
- **Filterable** -- project grid supports category filtering (All / Web / App / Brand).
- **Contact form** -- client-side validation with success/error feedback states.
- **Original images** -- all 19 images are bundled. No external image dependencies.
- **Custom properties** -- every color, radius, shadow, and transition is a CSS variable.
- **Google Fonts** -- Poppins, Nunito Sans, IBM Plex Mono loaded via Google Fonts CDN.
- **Font Awesome** -- icons loaded via cdnjs CDN.

## Getting Started

1. Open `index.html` in any modern browser. No server required.
2. Edit `assets/css/base.css` to swap colors, fonts, or spacing via CSS custom properties.
3. Replace images in `assets/img/` with your own.
4. Update copy in each HTML file.
